🧠 Brain Tumor Detection Using Deep Learning | CNN | TensorFlow

I’m excited to share my Brain Tumor Detection project, built using Deep Learning and Convolutional Neural Networks (CNNs) with TensorFlow and Keras.

🎯 Project Objective
The goal of this project is to classify brain MRI images into two categories: Tumor and No Tumor using a trained CNN model.

🛠️ Technologies Used

Python
TensorFlow & Keras
Convolutional Neural Networks (CNN)
NumPy
Matplotlib
Scikit-learn
Seaborn

⚙️ Key Features
✅ MRI image preprocessing and normalization
✅ CNN-based image classification
✅ Binary classification: Tumor / No Tumor
✅ Prediction on user-provided MRI images
✅ Confusion Matrix visualization using a heatmap
✅ Model evaluation using accuracy, precision, recall, and F1-score

📊 Model Performance

Accuracy: 84%

I also implemented a Confusion Matrix to analyze correct and incorrect predictions and better understand the model’s classification performance.

💡 What I Learned

Building and training a CNN model
Image preprocessing and normalization
Making predictions on new images
Evaluating a classification model using performance metrics
Visualizing model performance with a confusion matrix heatmap

This project helped me strengthen my understanding of Deep Learning, Computer Vision, and medical image classification.
